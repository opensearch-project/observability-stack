The GenAI Observability SDK works with any agent framework. Use `@observe` to wrap your agent's entry points and tools, and `enrich()` to capture model details. Auto-instrumentation handles LLM calls automatically.

Each example below shows a complete, runnable integration. All examples assume the [observability stack is running locally](/docs/get-started/installation/); `register()` sends to `http://localhost:4318` by default.

Whatever the framework, the same rules make the traces work in [Agent Traces](/docs/ai-observability/agent-tracing/) and [Agent Evaluations](/docs/agent-evals/):

- **Call `register()` once, before the framework builds its agent.** It owns the global tracer provider; most frameworks trace through it. Don't also set up the framework's own OTLP exporter.
- **One trace per turn, rooted at the agent span.** Wrap each request in `@observe(op=Op.INVOKE_AGENT)` and call `mark_agent_root()` inside it when the agent runs in an HTTP handler, a job, or below another framework span. Never continue an incoming `traceparent` whose parent is not exported to the same OpenSearch. See [One trace per turn](/docs/send-data/ai-agents/python/#one-trace-per-turn-rooted-at-the-agent).
- **Sessions:** set `gen_ai.conversation.id` on every turn (`enrich(session_id=...)`, or the framework's trace attributes), stable for the whole conversation.
- **Messages:** record the question and answer as `gen_ai.input.messages` / `gen_ai.output.messages`, so online evaluators can read them back.
- **Evaluations:** keep the agent span's trace and span ids; `score()` and `Benchmark` link results to them. See [Evaluation & Scoring](/docs/agent-evals/evaluation/).

TypeScript frameworks (Strands for TypeScript, LangGraph.js, the Vercel AI SDK) follow the same rules with `withObserve()`, `markAgentRoot()` and `enrich({ sessionId })`. See the [TypeScript SDK](/docs/send-data/ai-agents/typescript/#what-agent-traces-needs).

## Strands Agents

[Strands Agents](https://github.com/strands-agents/sdk-python) traces with the global OpenTelemetry tracer provider and emits `invoke_agent`, `execute_event_loop_cycle`, `chat` and `execute_tool` spans with GenAI attributes. After `register()`, those spans are exported with yours: do not also call `StrandsTelemetry().setup_otlp_exporter()`, which would install a second exporter.

```bash
pip install opensearch-genai-observability-sdk-py strands-agents
export OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental  # latest GenAI attribute names
```

```python
from strands import Agent, tool
from strands.models.bedrock import BedrockModel

from opensearch_genai_observability_sdk_py import Op, enrich, mark_agent_root, observe, register

AGENT_NAME, AGENT_VERSION = "travel_assistant", "v1"
register(service_name="strands-agent", agent_name=AGENT_NAME, agent_version=AGENT_VERSION)


@tool
def weather(city: str) -> str:
    """Get weather for a city."""
    return f"72F and sunny in {city}"


def _messages(role, text):
    return [{"role": role, "parts": [{"type": "text", "content": text}]}]


@observe(name=AGENT_NAME, op=Op.INVOKE_AGENT)
def ask(conversation_id: str, question: str) -> str:
    mark_agent_root()  # this span, not Strands' inner invoke_agent, is the agent run
    enrich(session_id=conversation_id, input_messages=_messages("user", question),
           **{"gen_ai.agent.version": AGENT_VERSION})
    agent = Agent(
        name=AGENT_NAME,
        model=BedrockModel(model_id="us.anthropic.claude-sonnet-4-20250514-v1:0"),
        tools=[weather],
        system_prompt="You are a helpful travel assistant.",
        trace_attributes={"gen_ai.conversation.id": conversation_id},
    )
    answer = str(agent(question))
    enrich(output_messages=_messages("assistant", answer))
    return answer


ask("conversation-42", "What's the weather in Seattle?")
```

Strands' spans nest under the `@observe` agent span, so one trace per turn shows the whole run: model calls with token usage, and each tool call with its arguments and result. Use `@observe` for custom logic that Strands doesn't trace (API calls, database queries, post-processing).

## LangGraph

[LangGraph](https://langchain-ai.github.io/langgraph/) builds stateful, multi-step agent workflows. Install the LangChain auto-instrumentor for automatic LLM tracing.

```bash
pip install "opensearch-genai-observability-sdk-py[langchain]" langgraph langchain-openai
```

```python
from opensearch_genai_observability_sdk_py import register, observe, Op, enrich
from langgraph.graph import StateGraph, START, END
from langchain_openai import ChatOpenAI
from typing import TypedDict

register(service_name="langgraph-agent")  # OTLP to http://localhost:4318

class State(TypedDict):
    query: str
    result: str

@observe(op=Op.CHAT, name="llm_call")
def call_model(state: State) -> dict:
    llm = ChatOpenAI(model="gpt-4o")
    response = llm.invoke(state["query"])
    enrich(model="gpt-4o", provider="openai")
    return {"result": response.content}

@observe(op=Op.EXECUTE_TOOL)
def check_facts(state: State) -> dict:
    # fact-checking logic
    return {"result": f"Verified: {state['result']}"}

graph = StateGraph(State)
graph.add_node("model", call_model)
graph.add_node("fact_check", check_facts)
graph.add_edge(START, "model")
graph.add_edge("model", "fact_check")
graph.add_edge("fact_check", END)
app = graph.compile()

@observe(op=Op.INVOKE_AGENT, name="fact_check_agent")
def run(query: str) -> str:
    result = app.invoke({"query": query, "result": ""})
    return result["result"]

run("What is OpenSearch?")
```

## CrewAI

[CrewAI](https://www.crewai.com/) orchestrates role-playing AI agents. Wrap crew execution with `@observe`. The `[otel-instrumentors]` extra includes auto-instrumentation for CrewAI's internal LLM calls.

```bash
pip install "opensearch-genai-observability-sdk-py[otel-instrumentors]" crewai
```

```python
from opensearch_genai_observability_sdk_py import register, observe, Op, enrich
from crewai import Agent, Task, Crew

register(service_name="crewai-agent")  # OTLP to http://localhost:4318

researcher = Agent(
    role="Researcher",
    goal="Find accurate information",
    backstory="Expert research analyst",
    llm="gpt-4o",
)

writer = Agent(
    role="Writer",
    goal="Write clear summaries",
    backstory="Technical writer",
    llm="gpt-4o",
)

@observe(op=Op.INVOKE_AGENT, name="research_crew")
def run_crew(topic: str) -> str:
    enrich(model="gpt-4o", provider="openai")
    research_task = Task(
        description=f"Research: {topic}",
        expected_output="Key findings",
        agent=researcher,
    )
    write_task = Task(
        description="Summarize the research findings",
        expected_output="Clear summary",
        agent=writer,
    )
    crew = Crew(agents=[researcher, writer], tasks=[research_task, write_task])
    result = crew.kickoff()
    return str(result)

run_crew("OpenTelemetry observability for AI agents")
```

## OpenAI Agents SDK

The [OpenAI Agents SDK](https://openai.github.io/openai-agents-python/) has built-in tracing. Install the OpenAI auto-instrumentor to capture all LLM calls, and use `@observe` for top-level orchestration.

```bash
pip install "opensearch-genai-observability-sdk-py[openai]" openai-agents
```

```python
from opensearch_genai_observability_sdk_py import register, observe, Op, enrich
from agents import Agent, Runner  # openai-agents package

register(service_name="openai-agents")  # OTLP to http://localhost:4318

agent = Agent(
    name="assistant",
    instructions="You are a helpful assistant.",
    model="gpt-4o",
)

@observe(op=Op.INVOKE_AGENT, name="openai_agent")
def run(query: str) -> str:
    enrich(model="gpt-4o", provider="openai")
    result = Runner.run_sync(agent, query)
    enrich(
        input_tokens=result.raw_responses[-1].usage.input_tokens,
        output_tokens=result.raw_responses[-1].usage.output_tokens,
    )
    return result.final_output

run("Explain observability in three sentences.")
```

## Amazon Bedrock

For direct Bedrock `converse` or `invoke_model` calls, install the Bedrock auto-instrumentor.

```bash
pip install "opensearch-genai-observability-sdk-py[bedrock]"
```

```python
from opensearch_genai_observability_sdk_py import register, observe, Op, enrich
import boto3

register(service_name="bedrock-agent")  # OTLP to http://localhost:4318

@observe(op=Op.INVOKE_AGENT, name="bedrock_agent")
def run(query: str) -> str:
    client = boto3.client("bedrock-runtime", region_name="us-east-1")
    enrich(model="claude-sonnet-4-20250514", provider="bedrock")
    response = client.converse(
        modelId="us.anthropic.claude-sonnet-4-20250514-v1:0",
        messages=[{"role": "user", "content": [{"text": query}]}],
    )
    result = response["output"]["message"]["content"][0]["text"]
    enrich(
        input_tokens=response["usage"]["inputTokens"],
        output_tokens=response["usage"]["outputTokens"],
    )
    return result

run("What is OpenSearch?")
```
