The GenAI Observability SDK works with any agent framework. Use `@observe` to wrap your agent's entry points and tools, and `enrich()` to capture model details. Auto-instrumentation handles LLM calls automatically.

Each framework section below is a complete, runnable example that does the same things end to end: it traces a two-turn conversation with one tool, scores each turn online and the whole conversation once, and runs a small offline test suite twice so the runs can be compared. Every example ran against a real model on Amazon Bedrock and was checked in OpenSearch, in [Agent Traces](/docs/ai-observability/agent-tracing/) and in [Agent Evaluations](/docs/agent-evals/). All examples assume the [observability stack is running locally](/docs/get-started/installation/); `register()` sends to `http://localhost:4318` by default.

<Aside type="note" title="SDK versions">
The examples need the Python SDK 0.3.0 or later (`pip install "opensearch-genai-observability-sdk-py>=0.3.0"`) and the TypeScript SDK 0.2.0 or later (`npm install "@opensearch-project/genai-observability-sdk-ts@>=0.2.0"`). If an import such as `mark_agent_root` fails, upgrade.
</Aside>

## The rules every framework follows

Whatever the framework, the same rules make the traces work in Agent Traces and Agent Evaluations:

- **Call `register()` once, before the framework builds its agent.** It owns the global tracer provider; most frameworks trace through it. Don't also set up the framework's own OTLP exporter. `register(service_name=..., agent_name=..., agent_version=...)` sets the service name of the spans and stamps the agent name and version on every evaluation result.
- **Install the extra and the library.** An SDK extra (for example `[bedrock]`) installs only the OpenTelemetry instrumentor, not the library it instruments. `register()` activates an instrumentor only when its library is installed. Quote the extra (`"opensearch-genai-observability-sdk-py[bedrock]>=0.3.0"`): zsh treats unquoted brackets as a glob.
- **One trace per turn, rooted at your agent span.** Wrap each turn in `@observe(op=Op.INVOKE_AGENT)` and call `mark_agent_root()` inside it. Agent Traces lists as a trace's agent the span marked with `mark_agent_root()` (`derived.gen_ai.is_root`) or, without a mark, a GenAI span that has no parent. Most frameworks add their own `invoke_agent` spans below yours; the mark keeps your span the agent of the trace. Never continue an incoming `traceparent` whose parent is not exported to the same OpenSearch. See [One trace per turn](/docs/send-data/ai-agents/python/#one-trace-per-turn-rooted-at-the-agent).
- **Sessions:** set `gen_ai.conversation.id` on every turn with `enrich(session_id=...)`, stable for the whole conversation. The Sessions tab and session-level results group turns by it.
- **Messages:** record the question and answer as `gen_ai.input.messages` / `gen_ai.output.messages` with `enrich(input_messages=..., output_messages=...)`, so Agent Traces, the run page and online evaluators can read them back. Once `enrich()` sets the output messages, `@observe` no longer records the function's return value as the output.
- **Agent version on the span:** `register(agent_version=...)` stamps the version on results, not on spans. Put it on the agent span with `enrich(**{"gen_ai.agent.version": AGENT_VERSION})`.
- **Evaluations:** `score()` inside the agent span judges that span; `evaluate()` starts one agent span per case and links each result to it. See [Evaluation & Scoring](/docs/agent-evals/evaluation/).

## How the examples are built

Each Python example has two parts:

1. **The framework part** (different per framework, shown in each section): `register()`, the framework's agent and tool, and `ask(conversation_id, question, online_eval=True)`, which is one agent turn:
   - `@observe(name=AGENT_NAME, op=Op.INVOKE_AGENT)` and `mark_agent_root()`: this span is the turn's agent root.
   - `enrich(session_id=..., input_messages=..., **{"gen_ai.agent.version": AGENT_VERSION})`, then the framework call, then `enrich(output_messages=...)` with the answer.
   - The online evaluation: `score()` while the agent span is active, with `evaluator`, `evaluator_type` and `agent_version`. The result is linked to this span.
2. **The conversation and evaluation part** (the same in every Python example, shown once below): append it to the framework part and run the file.

The examples use Claude Haiku 4.5 on Amazon Bedrock (`us.anthropic.claude-haiku-4-5-20251001-v1:0`, region `us-west-2`) with AWS credentials from the default chain. Use any model id and region you have access to. Where a framework defaults to OpenAI, the section also shows the OpenAI variant.

### The conversation and evaluation part

```python
# 1. A two-turn conversation: both turns share gen_ai.conversation.id.
conversation_id = f"conv-{uuid.uuid4().hex[:8]}"
print(ask(conversation_id, "What's the weather in Seattle?"))
answer = ask(conversation_id, "Should I pack sunglasses there?")
print(answer)
# Session-level online evaluation: judges the whole conversation, linked by its id.
ok = "seattle" in answer.lower()
score("remembers_city", 1.0 if ok else 0.0, label="pass" if ok else "fail", level="session",
      conversation_id=conversation_id, explanation="turn 2 names the city from turn 1" if ok else "city lost",
      evaluator="context_check", evaluator_type="code", agent_version=AGENT_VERSION)


# 2. Offline evaluation: a small suite, run twice so the runs can be compared.
@scorer(name="mentions_expected", evaluator="expected_terms_check", evaluator_type="code",
        threshold=1.0, score_min=0, score_max=1,
        description="Share of the expected answer's key terms found in the answer")
def mentions_expected(input, output, expected):
    terms = re.findall(r"[a-z]{4,}|\d+", expected.lower())
    found = [t for t in terms if t in output.lower()]
    return EvalScore(name="mentions_expected", value=len(found) / len(terms),
                     explanation=f"found {found} of {terms}")


CASES = [
    {"case_id": "lisbon-weather", "case_name": "Weather in Lisbon",
     "input": "What's the weather in Lisbon?", "expected": "Lisbon: 72F and sunny"},
    {"case_id": "tokyo-weather", "case_name": "Weather in Tokyo",
     "input": "What's the weather in Tokyo?", "expected": "Tokyo: 72F and sunny"},
    {"case_id": "portugal-capital", "case_name": "Capital of Portugal",
     "input": "What is the capital of Portugal?", "expected": "Lisbon is the capital of Portugal"},
]

for run_name in ("baseline", "rerun"):
    evaluate(  # prints a summary per run
        f"{AGENT_NAME}-suite",
        task=lambda question: ask(f"eval-{uuid.uuid4().hex[:8]}", question, online_eval=False),
        data=CASES,
        scores=[mentions_expected],
        agent_name=AGENT_NAME, agent_version=AGENT_VERSION,
        run_name=run_name,
    )

provider.force_flush()
```

- **Two turns, one conversation.** Both turns share `gen_ai.conversation.id`; the second turn needs the first one's answer, so the framework must keep the conversation's history (each section shows how).
- **Online, per turn:** `concise_answer` from the `length_check` code evaluator, on each turn's agent span.
- **Online, per session:** `score(..., level="session", conversation_id=...)` judges the whole conversation. It carries `gen_ai.conversation.id` and no trace context.
- **Offline:** the `@scorer` declares the evaluator name and type, the pass threshold, the scale and a description. `evaluate()` runs the three cases of the suite `<agent>-suite`, once as `baseline` and once as `rerun`, stamps `test.suite.name`, `test.suite.run.id` and `test.case.id` on each case's agent span, links each result to it, and prints a summary per run. Each case gets its own conversation id, so cases don't share history, and `online_eval=False` keeps the online scores off the case traces.
- `provider.force_flush()` exports the last spans and results before a short script exits.

## Strands Agents

[Strands Agents](https://github.com/strands-agents/sdk-python) traces with the global OpenTelemetry tracer provider and emits `invoke_agent`, `execute_event_loop_cycle`, `chat` and `execute_tool` spans with GenAI attributes. After `register()`, those spans are exported with yours: no SDK extra is needed.

```bash
pip install "opensearch-genai-observability-sdk-py>=0.3.0" strands-agents
```

```python
import os
import re
import uuid

# Strands reads the opt-in when it builds its tracer: set it before importing Strands.
# Latest GenAI names, messages as span attributes, per-turn token usage on Strands' own agent span.
os.environ.setdefault(
    "OTEL_SEMCONV_STABILITY_OPT_IN",
    "gen_ai_latest_experimental,gen_ai_span_attributes_only,gen_ai_use_latest_invocation_tokens",
)

from strands import Agent, tool  # noqa: E402
from strands.models.bedrock import BedrockModel  # noqa: E402

from opensearch_genai_observability_sdk_py import (  # noqa: E402
    EvalScore, Op, enrich, evaluate, mark_agent_root, observe, register, score, scorer,
)

AGENT_NAME, AGENT_VERSION = "strands-travel-agent", "v1"
MODEL_ID = "us.anthropic.claude-haiku-4-5-20251001-v1:0"

# Strands traces through the global tracer provider that register() installs: no Strands exporter setup.
provider = register(service_name=AGENT_NAME, agent_name=AGENT_NAME, agent_version=AGENT_VERSION)


@tool
def weather(city: str) -> str:
    """Get weather for a city."""
    return f"72F and sunny in {city}"


def _messages(role, text):
    return [{"role": role, "parts": [{"type": "text", "content": text}]}]


_agents: dict[str, Agent] = {}  # one Strands agent per conversation keeps its history


def agent_for(conversation_id: str) -> Agent:
    if conversation_id not in _agents:
        _agents[conversation_id] = Agent(
            name=AGENT_NAME,
            model=BedrockModel(model_id=MODEL_ID),
            tools=[weather],
            system_prompt="You are a helpful travel assistant. Answer in one or two sentences.",
            trace_attributes={"gen_ai.conversation.id": conversation_id},
            callback_handler=None,  # no streaming to stdout
        )
    return _agents[conversation_id]


@observe(name=AGENT_NAME, op=Op.INVOKE_AGENT)
def ask(conversation_id: str, question: str, online_eval: bool = True) -> str:
    mark_agent_root()  # this span, not Strands' inner invoke_agent, is the agent run
    enrich(session_id=conversation_id, input_messages=_messages("user", question),
           **{"gen_ai.agent.version": AGENT_VERSION})
    answer = str(agent_for(conversation_id)(question)).strip()
    enrich(output_messages=_messages("assistant", answer))
    if online_eval:
        # Online evaluation: score() inside the agent span is linked to this span.
        ok = len(answer) <= 400
        score("concise_answer", 1.0 if ok else 0.0, label="pass" if ok else "fail",
              explanation=f"{len(answer)} characters", evaluator="length_check",
              evaluator_type="code", agent_version=AGENT_VERSION)
    return answer
```

Then append [the conversation and evaluation part](#the-conversation-and-evaluation-part).

- Don't call `StrandsTelemetry().setup_otlp_exporter()`: it would install a second exporter.
- Set `OTEL_SEMCONV_STABILITY_OPT_IN` before importing Strands (the example sets it with `os.environ.setdefault`, so the file runs without an export). `gen_ai_latest_experimental` alone writes the `chat` and `execute_tool` messages as span events; `gen_ai_span_attributes_only` makes them span attributes, which Agent Traces reads. With the agent reused, `gen_ai_use_latest_invocation_tokens` keeps each turn's token usage per turn instead of cumulative.
- Keep one `Agent` per conversation: a new `Agent` per turn forgets the earlier turns. `trace_attributes={"gen_ai.conversation.id": ...}` puts the id on Strands' own spans too, and `callback_handler=None` stops Strands from streaming the answer to stdout.
- Strands' own `invoke_agent` span sits under your agent span, with the same per-turn token usage. The agent span's `gen_ai.provider.name` is copied from it (`strands-agents`); add `provider="aws.bedrock"` to `enrich()` if you want the OTel provider name.
- Strands may print `Attempting to instrument while already instrumented` once at startup. It is harmless.

**In Agent Traces**, a turn that calls the tool has 7 spans: your `invoke_agent strands-travel-agent`, Strands' `invoke_agent`, two `execute_event_loop_cycle`, two `chat` (with model, tokens and messages) and `execute_tool weather`. A turn without a tool call has 4.

## Strands Agents (TypeScript)

[Strands Agents for TypeScript](https://github.com/strands-agents/sdk-typescript) follows the same rules with `withObserve()`, `markAgentRoot()` and `enrich()`. This is the full example, including the conversation and the evaluations.

```bash
npm install "@opensearch-project/genai-observability-sdk-ts@>=0.2.0" @strands-agents/sdk @modelcontextprotocol/client @opentelemetry/api@~1.9.0 @opentelemetry/context-async-hooks@^1 zod
export OTEL_SEMCONV_STABILITY_OPT_IN=gen_ai_latest_experimental,gen_ai_span_attributes_only
```

The SDK uses OpenTelemetry JS 1.x and Strands peers on 2.x, so add `legacy-peer-deps=true` to `.npmrc` before you install. With it, npm skips Strands' peer `@modelcontextprotocol/client`, which is why the install line names it. See [Installation](/docs/send-data/ai-agents/typescript/#installation). Use ES modules (`"type": "module"`) and run the file with `npx tsx app.ts`.

```typescript
import { ROOT_CONTEXT, context, trace } from "@opentelemetry/api";
import { AsyncLocalStorageContextManager } from "@opentelemetry/context-async-hooks";
import { Agent, BedrockModel, tool } from "@strands-agents/sdk";
import {
  Benchmark, type EvalScore, Op, enrich, markAgentRoot, register, score, withObserve,
} from "@opensearch-project/genai-observability-sdk-ts";
import { randomUUID } from "node:crypto";
import { z } from "zod";

const AGENT_NAME = "strands-ts-travel-agent";
const AGENT_VERSION = "v1";
const MODEL_ID = "us.anthropic.claude-haiku-4-5-20251001-v1:0";

// Async code keeps the active span (and score()'s link to it) only with a context manager.
context.setGlobalContextManager(new AsyncLocalStorageContextManager().enable());
const provider = await register({ serviceName: AGENT_NAME, agentName: AGENT_NAME, agentVersion: AGENT_VERSION });

const weather = tool({
  name: "weather",
  description: "Get weather for a city.",
  inputSchema: z.object({ city: z.string() }),
  callback: ({ city }) => `72F and sunny in ${city}`,
});

const agents = new Map<string, Agent>(); // one Strands agent per conversation keeps its history
function agentFor(conversationId: string): Agent {
  let agent = agents.get(conversationId);
  if (!agent) {
    agent = new Agent({
      name: AGENT_NAME,
      model: new BedrockModel({ modelId: MODEL_ID }),
      tools: [weather],
      systemPrompt: "You are a helpful travel assistant. Answer in one or two sentences.",
      printer: false,
      traceAttributes: { "gen_ai.conversation.id": conversationId },
    });
    agents.set(conversationId, agent);
  }
  return agent;
}

const text = (role: string, content: string) => [{ role, parts: [{ type: "text", content }] }];

// One turn = one trace, rooted at this span. Returns the span ids so offline results can link to it.
function ask(conversationId: string, question: string, onlineEval = true) {
  return context.with(ROOT_CONTEXT, () =>
    withObserve(AGENT_NAME, { op: Op.INVOKE_AGENT }, async (span) => {
      markAgentRoot();
      span.setAttribute("gen_ai.agent.version", AGENT_VERSION);
      enrich({ sessionId: conversationId, inputMessages: text("user", question) });
      const result = await agentFor(conversationId).invoke(question);
      const answer = String(result).trim();
      // Strands reports lifetime totals on its own span: record this turn's usage on the agent span.
      const usage = result.metrics?.agentInvocations.at(-1)?.usage;
      enrich({ outputMessages: text("assistant", answer), inputTokens: usage?.inputTokens, outputTokens: usage?.outputTokens });
      if (onlineEval) {
        // Online evaluation: score() inside the agent span is linked to this span.
        const ok = answer.length <= 400;
        score({ name: "concise_answer", value: ok ? 1 : 0, label: ok ? "pass" : "fail",
                explanation: `${answer.length} characters`, evaluator: "length_check",
                evaluatorType: "code", agentVersion: AGENT_VERSION });
      }
      const { traceId, spanId } = trace.getActiveSpan()!.spanContext();
      return { answer, traceId, spanId };
    }),
  );
}

// 1. A two-turn conversation: both turns share gen_ai.conversation.id.
const conversationId = `conv-${randomUUID().slice(0, 8)}`;
console.log((await ask(conversationId, "What's the weather in Seattle?")).answer);
const { answer } = await ask(conversationId, "Should I pack sunglasses there?");
console.log(answer);
// Session-level online evaluation: judges the whole conversation, linked by its id.
const remembers = answer.toLowerCase().includes("seattle");
score({ name: "remembers_city", value: remembers ? 1 : 0, label: remembers ? "pass" : "fail", level: "session",
        conversationId, explanation: remembers ? "turn 2 names the city from turn 1" : "city lost",
        evaluator: "context_check", evaluatorType: "code", agentVersion: AGENT_VERSION });

// 2. Offline evaluation: a small suite, run twice so the runs can be compared.
// evaluate() needs a synchronous task, so an async agent logs each case with Benchmark.
function mentionsExpected(output: string, expected: string): EvalScore {
  const terms = expected.toLowerCase().match(/[a-z]{4,}|\d+/g) ?? [];
  const found = terms.filter((t) => output.toLowerCase().includes(t));
  return { name: "mentions_expected", value: found.length / terms.length, threshold: 1, scoreMin: 0, scoreMax: 1,
           explanation: `found ${JSON.stringify(found)} of ${JSON.stringify(terms)}` };
}

const CASES = [
  { caseId: "lisbon-weather", caseName: "Weather in Lisbon", input: "What's the weather in Lisbon?", expected: "Lisbon: 72F and sunny" },
  { caseId: "tokyo-weather", caseName: "Weather in Tokyo", input: "What's the weather in Tokyo?", expected: "Tokyo: 72F and sunny" },
  { caseId: "portugal-capital", caseName: "Capital of Portugal", input: "What is the capital of Portugal?", expected: "Lisbon is the capital of Portugal" },
];

for (const runName of ["baseline", "rerun"]) {
  const bench = new Benchmark(`${AGENT_NAME}-suite`, { runName, agentName: AGENT_NAME, agentVersion: AGENT_VERSION });
  for (const c of CASES) {
    const { answer, traceId, spanId } = await ask(`eval-${randomUUID().slice(0, 8)}`, c.input, false);
    bench.log({
      caseId: c.caseId, caseName: c.caseName, input: c.input, output: answer, expected: c.expected,
      traceId, spanId, // links each result to the case's agent span
      scores: [mentionsExpected(answer, c.expected)],
      evaluator: "expected_terms_check", evaluatorType: "code",
    });
  }
  bench.close(); // prints the run summary
}

await provider.forceFlush();
```

- Set up the `AsyncLocalStorageContextManager` before `register()`. Without it, `score()` inside `withObserve()` has no active span and the result has no trace link.
- `context.with(ROOT_CONTEXT, ...)` makes every turn its own trace.
- **Offline:** in TypeScript `evaluate()` takes a synchronous task, and a Strands agent is async, so the example logs each case with `Benchmark`, passing the `traceId` and `spanId` that `ask()` returns. `Benchmark` stamps `test.*` on the results, not on the agent spans: the run page, Compare and the result flyout work (they link by span id), but Agent Traces cannot filter the case traces by suite or run.
- Without the opt-in, Strands for TypeScript writes older attribute names (`gen_ai.system` instead of `gen_ai.provider.name`), puts messages on span events, and records no tool arguments or results.
- Strands for TypeScript reports lifetime token totals on its own `invoke_agent` span once the agent is reused across turns, and has no opt-in to change that. The example records each turn's usage (`result.metrics.agentInvocations.at(-1).usage`) on your agent span.
- The TypeScript `EvalScore` has no evaluator description, so the result flyout has no "What it checks" for these results.
- `BedrockModel` warns about the default `maxTokens`. It is harmless.

**In Agent Traces**, a tool turn has 7 spans: your agent span, Strands' `invoke_agent`, two `execute_agent_loop_cycle`, two `chat` and `execute_tool weather`. The `execute_agent_loop_cycle` spans have no `gen_ai.operation.name`, so the summary's **Total Spans** does not count them.

## LangGraph

[LangGraph](https://langchain-ai.github.io/langgraph/) builds stateful agent workflows. The LangChain instrumentor in the `[langchain]` extra traces each model call as a `chat` span with model, token usage and messages, and each tool call as an `execute_tool` span.

```bash
pip install "opensearch-genai-observability-sdk-py[langchain]>=0.3.0" langgraph langchain-aws
```

```python
import re
import uuid
from typing import Annotated, TypedDict

from langchain_aws import ChatBedrockConverse
from langchain_core.messages import HumanMessage
from langchain_core.tools import tool
from langgraph.checkpoint.memory import InMemorySaver
from langgraph.graph import START, StateGraph
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode, tools_condition

from opensearch_genai_observability_sdk_py import (
    EvalScore, Op, enrich, evaluate, mark_agent_root, observe, register, score, scorer,
)

AGENT_NAME, AGENT_VERSION = "langgraph-travel-agent", "v1"
MODEL_ID = "us.anthropic.claude-haiku-4-5-20251001-v1:0"

# register() activates the LangChain instrumentor from the [langchain] extra.
provider = register(service_name=AGENT_NAME, agent_name=AGENT_NAME, agent_version=AGENT_VERSION)


@tool
def weather(city: str) -> str:
    """Get weather for a city."""
    return f"72F and sunny in {city}"


class State(TypedDict):
    messages: Annotated[list, add_messages]


llm = ChatBedrockConverse(model=MODEL_ID).bind_tools([weather])


def call_model(state: State) -> dict:  # the LangChain instrumentor traces each model call as a chat span
    return {"messages": [llm.invoke(state["messages"])]}


graph = StateGraph(State)
graph.add_node("model", call_model)
graph.add_node("tools", ToolNode([weather]))
graph.add_edge(START, "model")
graph.add_conditional_edges("model", tools_condition)
graph.add_edge("tools", "model")
app = graph.compile(checkpointer=InMemorySaver())  # keeps each thread's (conversation's) history


def _messages(role, text):
    return [{"role": role, "parts": [{"type": "text", "content": text}]}]


@observe(name=AGENT_NAME, op=Op.INVOKE_AGENT)
def ask(conversation_id: str, question: str, online_eval: bool = True) -> str:
    mark_agent_root()  # this span, not LangGraph's own workflow span, is the agent run
    enrich(session_id=conversation_id, input_messages=_messages("user", question),
           model=MODEL_ID, provider="aws.bedrock", **{"gen_ai.agent.version": AGENT_VERSION})
    result = app.invoke({"messages": [HumanMessage(question)]},
                        config={"configurable": {"thread_id": conversation_id}})
    answer = result["messages"][-1].text.strip()
    enrich(output_messages=_messages("assistant", answer))
    if online_eval:
        # Online evaluation: score() inside the agent span is linked to this span.
        ok = len(answer) <= 400
        score("concise_answer", 1.0 if ok else 0.0, label="pass" if ok else "fail",
              explanation=f"{len(answer)} characters", evaluator="length_check",
              evaluator_type="code", agent_version=AGENT_VERSION)
    return answer
```

Then append [the conversation and evaluation part](#the-conversation-and-evaluation-part).

**OpenAI models:** install `langchain-openai` instead of `langchain-aws`, and swap the model and the provider on the agent span:

```python
from langchain_openai import ChatOpenAI

MODEL_ID = "gpt-4o"
llm = ChatOpenAI(model=MODEL_ID).bind_tools([weather])  # any LangChain chat model works
# in ask(): enrich(..., model=MODEL_ID, provider="openai", ...)
```

- Don't wrap the model call in `@observe(op=Op.CHAT)`: the LangChain instrumentor already emits the `chat` span, and a second span would duplicate it.
- The checkpointer's `thread_id` (the conversation id) keeps each conversation's history; `enrich(session_id=...)` puts the same id on the agent span for Sessions.
- Set `model=` and `provider=` in `enrich()`: without `provider`, the agent span inherits `gen_ai.provider.name` `langgraph` from LangGraph's span. The agent span's token usage is the sum of its `chat` spans.
- The instrumentor records a tool call's arguments and result in LangChain's callback format (`input_str`, `tags`, `metadata`, and a serialized `ToolMessage`), so the tool span shows that payload rather than the plain arguments.
- The instrumentor also writes agent names on LangGraph's own spans (`LangGraph`, and node names such as `model` and `tools`), so they appear in the agent-name facets. Your marked span stays the agent of the trace.

**In Agent Traces**, a tool turn has 11 spans: your agent span, `invoke_agent LangGraph`, `LangGraph.workflow`, `execute_task` spans for the `model`, `tools` and `tools_condition` nodes, two `ChatBedrockConverse.chat` spans and `execute_tool weather`.

## Amazon Bedrock

For direct Bedrock `converse` calls, the Bedrock instrumentor in the `[bedrock]` extra traces each call as a `chat` span with model, tokens and messages. You write the tool loop yourself.

```bash

```

```python
import re
import uuid

    EvalScore, Op, enrich, evaluate, mark_agent_root, observe, register, score, scorer,

AGENT_NAME, AGENT_VERSION = "bedrock-travel-agent", "v1"
MODEL_ID = "us.anthropic.claude-haiku-4-5-20251001-v1:0"

    "inputSchema": {"json": {"type": "object", "properties": {"city": {"type": "string"}}, "required": ["city"]}}}}]}
SYSTEM = [{"text": "You are a helpful travel assistant. Answer in one or two sentences."}]


@observe(op=Op.EXECUTE_TOOL)  # your own tool code: @observe records its arguments and result

    return f"72F and sunny in {city}"


def _messages(role, text):
    return [{"role": role, "parts": [{"type": "text", "content": text}]}]


_history: dict[str, list] = {}  # the Converse messages of each conversation


@observe(name=AGENT_NAME, op=Op.INVOKE_AGENT)
def ask(conversation_id: str, question: str, online_eval: bool = True) -> str:
    mark_agent_root()
    enrich(session_id=conversation_id, input_messages=_messages("user", question),
           model=MODEL_ID, provider="aws.bedrock", **{"gen_ai.agent.version": AGENT_VERSION})
    messages = _history.setdefault(conversation_id, [])
    messages.append({"role": "user", "content": [{"text": question}]})
    tokens_in = tokens_out = 0

        tokens_in += response["usage"]["inputTokens"]
        tokens_out += response["usage"]["outputTokens"]
        message = response["output"]["message"]
        messages.append(message)
        if response["stopReason"] != "tool_use":
            break
        messages.append({"role": "user", "content": [
            {"toolResult": {"toolUseId": c["toolUse"]["toolUseId"], "content": [{"text": weather(**c["toolUse"]["input"])}]}}
            for c in message["content"] if "toolUse" in c]})
    answer = "".join(c.get("text", "") for c in message["content"]).strip()
    enrich(input_tokens=tokens_in, output_tokens=tokens_out, output_messages=_messages("assistant", answer))
    if online_eval:
        # Online evaluation: score() inside the agent span is linked to this span.
        ok = len(answer) <= 400
        score("concise_answer", 1.0 if ok else 0.0, label="pass" if ok else "fail",
              explanation=f"{len(answer)} characters", evaluator="length_check",
              evaluator_type="code", agent_version=AGENT_VERSION)
    return answer
```

## Langfuse

If your app is already traced with [Langfuse](https://langfuse.com/) (Python SDK v3 or later, which is built on OpenTelemetry), keep Langfuse and add OpenSearch as a second destination. Both backends then receive the same spans with the same trace and span ids, which is what lets you mirror Langfuse scores later (see [Evaluation Integrations: Langfuse](/docs/agent-evals/evaluation-integrations/#langfuse)).

```bash
pip install "opensearch-genai-observability-sdk-py>=0.3.0" langfuse
export LANGFUSE_PUBLIC_KEY=pk-lf-... LANGFUSE_SECRET_KEY=sk-lf-... LANGFUSE_BASE_URL=https://<your-langfuse-host>
```

The examples use the Langfuse Python SDK (`get_client`, `@observe`, `propagate_attributes`).

**Call `register()` before Langfuse starts.** Langfuse attaches its span processor to the global tracer provider if one exists, and otherwise installs its own. `register()` must therefore run before `get_client()`, `Langfuse()` or the first `@observe` call. If Langfuse goes first, OpenTelemetry keeps Langfuse's provider, logs `Overriding of current TracerProvider is not allowed`, and nothing reaches OpenSearch.

```python
from opensearch_genai_observability_sdk_py import register

provider = register(service_name="travel-agent", agent_name="travel_assistant", agent_version="v1")

from langfuse import get_client, observe, propagate_attributes  # after register()

langfuse = get_client()
```

Langfuse still decides which spans it keeps (its own spans and spans with GenAI attributes); OpenSearch receives every span the app creates.

### Frameworks that emit GenAI attributes

Frameworks that already write OpenTelemetry GenAI attributes, for example [Strands Agents](#strands-agents) with the opt-in flags from its section, need nothing else. Keep your Langfuse code as it is:

```python
@observe(name="travel_assistant")

    with propagate_attributes(session_id=conversation_id, user_id=user_id):
        return str(agent(question))  # a Strands Agent
```

Agent Traces lists each turn by the framework's `invoke_agent` span, below the Langfuse span. `propagate_attributes(session_id=...)` writes `session.id` on every span, and Data Prepper copies it to `gen_ai.conversation.id`, so turns group into sessions.

### Langfuse-native spans: copy `langfuse.*` to `gen_ai.*`

Spans created by Langfuse itself (`@observe`, the LangChain / LangGraph `CallbackHandler`, the Langfuse OpenAI wrapper) carry only `langfuse.*` attributes, so Agent Traces does not recognize them. Wrap the OpenSearch exporter with a small translator that copies them to the GenAI names (existing `gen_ai.*` keys are never overwritten, and the `langfuse.*` keys are kept):

```python
# langfuse_genai.py
import json

from opentelemetry.sdk.trace import ReadableSpan
from opentelemetry.sdk.trace.export import SpanExporter

_OPERATIONS = {"agent": "invoke_agent", "generation": "chat", "tool": "execute_tool",
               "embedding": "embeddings", "retriever": "retrieval"}


def _messages(value, role):
    """Langfuse input or output (JSON) -> GenAI messages in parts format."""
    try:
        data = json.loads(value)
    except (TypeError, ValueError):
        data = value
    if isinstance(data, dict) and "messages" in data:  # LangGraph state
        data = data["messages"]
    if isinstance(data, dict) and set(data) >= {"role", "content"}:
        data = [data]
    if isinstance(data, list) and data and all(isinstance(m, dict) and "content" in m for m in data):
        out = []
        for m in data:
            text = m["content"] if isinstance(m["content"], str) else json.dumps(m["content"], default=str)
            r = m.get("role") or {"human": "user", "ai": "assistant"}.get(m.get("type"), m.get("type", role))
            out.append({"role": r, "parts": [{"type": "text", "content": text}]})
        return json.dumps(out)
    if isinstance(data, dict) and set(data) == {"args", "kwargs"}:  # @observe() arguments
        data = data["args"][0] if len(data["args"]) == 1 and not data["kwargs"] else data
    text = data if isinstance(data, str) else json.dumps(data, default=str)
    return json.dumps([{"role": role, "parts": [{"type": "text", "content": text}]}])


def langfuse_to_genai(attrs, name):
    a, new = dict(attrs), {}
    op = _OPERATIONS.get(str(a.get("langfuse.observation.type", "")).lower())
    if op == "invoke_agent" and "langfuse.observation.metadata.langgraph_node" in a:
        op = None  # a LangGraph node that Langfuse types "agent", not a separate agent
    if op:
        new["gen_ai.operation.name"] = op
        if op == "invoke_agent":
            new["gen_ai.agent.name"] = name.removeprefix("invoke_agent ").strip()
            if "langfuse.version" in a:
                new["gen_ai.agent.version"] = a["langfuse.version"]
        if op == "execute_tool":
            new["gen_ai.tool.name"] = name
        if "langfuse.observation.input" in a:
            new["gen_ai.input.messages"] = _messages(a["langfuse.observation.input"], "user")
        if "langfuse.observation.output" in a:
            new["gen_ai.output.messages"] = _messages(a["langfuse.observation.output"], "assistant")
    if "langfuse.observation.model.name" in a:
        new["gen_ai.request.model"] = a["langfuse.observation.model.name"]
    try:
        usage = json.loads(a.get("langfuse.observation.usage_details") or "{}")
        for src, dst in (("input", "input_tokens"), ("output", "output_tokens"), ("total", "total_tokens")):
            if isinstance(usage.get(src), (int, float)):
                new[f"gen_ai.usage.{dst}"] = int(usage[src])
    except (TypeError, ValueError):
        pass
    session = a.get("session.id") or a.get("langfuse.session.id")
    if session:
        new["gen_ai.conversation.id"] = session
    for k, v in new.items():
        a.setdefault(k, v)
    return a


class LangfuseToGenAIExporter(SpanExporter):
    def __init__(self, inner: SpanExporter):
        self._inner = inner

    def export(self, spans):
        return self._inner.export([ReadableSpan(
            name=s.name, context=s.context, parent=s.parent, resource=s.resource,
            attributes=langfuse_to_genai(s.attributes or {}, s.name), events=s.events, links=s.links,
            kind=s.kind, status=s.status, start_time=s.start_time, end_time=s.end_time,
            instrumentation_scope=s.instrumentation_scope) for s in spans])

    def shutdown(self):
        self._inner.shutdown()

    def force_flush(self, timeout_millis=30000):
        return self._inner.force_flush(timeout_millis)
```

Save it next to your app and pass it to `register()`. With a custom exporter, also give the logs endpoint so evaluation results are exported. The example below is a LangGraph agent (`graph`) traced with Langfuse's `CallbackHandler`:

```python
from opentelemetry.exporter.otlp.proto.http.trace_exporter import OTLPSpanExporter
from opensearch_genai_observability_sdk_py import register
from langfuse_genai import LangfuseToGenAIExporter

provider = register(
    service_name="travel-agent", agent_name="travel_assistant", agent_version="v1",
    exporter=LangfuseToGenAIExporter(OTLPSpanExporter(endpoint="http://localhost:4318/v1/traces")),
    logs_endpoint="http://localhost:4318/v1/logs",
)

from langfuse import get_client, observe, propagate_attributes
from langfuse.langchain import CallbackHandler

langfuse = get_client()


@observe(name="travel_assistant", as_type="agent")  # this span becomes the agent root
def ask(question: str) -> str:
    with propagate_attributes(session_id=conversation_id, user_id=user_id, version="v1"):
        state = graph.invoke({"messages": [{"role": "user", "content": question}]},
                             config={"callbacks": [CallbackHandler()]})
        return state["messages"][-1].content
```

`as_type="agent"` on the entry function gives each turn one agent root named after the agent, with the messages, model and token totals of its LangChain calls. Langfuse's `CallbackHandler` writes every LangChain and LangGraph metadata key as a `langfuse.observation.metadata.*` attribute; keep custom metadata keys few, as each one is a field in the span index.
